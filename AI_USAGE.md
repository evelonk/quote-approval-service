## Подготовка Python API и проверка запуска

**Ответственная участница:** M3

**Задача:** подготовить минимальное API создания и чтения черновика с сохранением в PostgreSQL и проверкой доступа.

**Как использовали ИИ:** с помощью ИИ подготовлены код приложения, автоматические тесты, конфигурация Docker Compose и инструкция запуска.

**Что вошло в проект:** Python API на FastAPI и SQLAlchemy, аутентификация HTTP Basic с хешами Argon2, проверки роли и принадлежности черновика, учебные записи, тесты и инструкция.

**Проверка человеком:** запустила приложение через Docker Compose и тесты — 17 проверок прошли. Вручную проверила создание черновика (`201`), чтение владельцем (`200`), отказ другому менеджеру (`404`) и запросу без входа (`401`). После остановки и повторного запуска контейнеров прочитала тот же черновик: данные сохранились.
