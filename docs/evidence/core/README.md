## Что подтверждено

| Свойство | Проверка |
| --- | --- |
| Расчет и валидация | 100 × 2 со скидкой 10% дает 180; 15% дает 170. Проверены округление, переполнение, запрещенные поля, неизвестные и повторяющиеся товары, срок и точность чисел |
| Неизменность версии | Редактирование после фиксации запрещено; изменение каталога не меняет старые суммы; новая версия не наследует одобрение |
| Права и ответы | Запрет чужой организации, чужой роли и несвязанной пары ID; отсутствие внутренних решений и комментариев в клиентских ответах и истории |
| Переходы | Стандартный сценарий, согласование/возврат, отправка, решение клиента, новая версия, отказы при повторах |
| Срок | Истечение записывается один раз даже при отказе в принятии; принятое решение не заменяется истечением; срок до отправки допускает новый черновик без изменения прежних условий |
| Транзакции | Искусственная ошибка записи события при редактировании, фиксации, согласовании, отправке, решении и создании новой версии откатывает изменения |
| Конкурентность PostgreSQL | Два решения дают один успех и один отказ; два чтения истечения дают одно событие; одновременное создание следующей версии дает один новый черновик; запрос, ожидавший блокировку до срока, после освобождения получает отказ |
| Обновление схемы | Создана исходная схема из трех таблиц; после обновления и повторной инициализации сохранены старый ID, комментарий и хеш пароля; создана ровно одна версия и одно событие |

## Сборка и HTTP

Выполнена сборка отдельного образа:

```bash
docker build -t quote-approval-core-review:20261109 .
```

Образ собран успешно. Из него запущены `python -m app.init_db` и uvicorn,
подключенные к отдельной временной PostgreSQL. Внешний порт не публиковался.
Выполнен [HTTP-сценарий](../../../scripts/smoke_core.py) стандартной библиотекой
Python против запущенного сервера, не через TestClient.

Сокращенный протокол:

- `/health`: 200;
- создание предложений: 201;
- заполнение и фиксация: 200, суммы 180.00 и 170.00;
- отправка скидки 15% до согласования: 409;
- одобрение руководителем и отправка: 200;
- чтение другим менеджером и клиентом другой организации: 404;
- клиентский ответ не содержит внутренний комментарий и решение руководителя;
- принятие стандартной версии и отклонение согласованной: 200;
- повторное решение второго представителя той же организации: 409;
- чтение истории: 200;
- создание второй версии после отклонения: 201, новый ID и номер 2.

## Ограничения

- GitHub Actions для нового ядра еще не запускался: workflow подготовлен локально.
- Человеческая проверка и воспроизведение другим участником еще не выполнены.
- Не проверялись нагрузка, несколько одновременно запускаемых инициализаторов,
  SAST, поиск секретов, SCA и DAST. Эти проверки не заменены тестами.
- Блокировки берутся и на предложение, поэтому операции над его разными версиями
  сериализуются. Это сознательное упрощение для небольшого учебного продукта.
- Уточнение поведения при сроке, наступившем до отправки, и правила округления
  требуют содержательной проверки командой.
